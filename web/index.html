How to

  1. Connect the board's UART USB connector (the USB-to-serial bridge) to the computer, not the native USB port that will host the joystick.
  2. Click Connect, pick the serial port of the board and choose Install. Tick "erase device" the first time to start from a clean configuration.
  3. If the port does not show up or the connection fails, hold BOOT, tap RESET, release BOOT and try again.
  4. After flashing, open the serial console (115200 baud) from the same dialog or with pio device monitor and type help to configure the mapping.

Wiring reminder

Defaults: SBUS on GPIO17, CPPM on GPIO18, ground to ground. The joystick needs 5 V on the native USB port, which the DevKitC-1 cannot supply by itself (diode D7 blocks it): use an OTG Y-cable with a power input, or wire the 5V pin to VBUS. Wiring and EdgeTX setup for the TX16S MKII are in the README.
